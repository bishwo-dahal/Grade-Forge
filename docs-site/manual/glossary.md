# Glossary

**Assignment**  
Work item with a due flow, description, optional tests and rubric, and submissions.

**Class**  
A section or offering of a course students and faculty use together.

**Course**  
Catalog object that can contain one or more classes depending on your school.

**Dashboard**  
Home view after sign-in for students, faculty, and grading assistants.

**Grading assistant (GA)**  
Role that grades in assigned courses under faculty direction.

**Main group**  
Group bucket faculty configure for group assignments (see class **Groups**).

**Plagiarism and AI report**  
Similarity and AI-signal style report faculty may generate for an assignment. Assistive only.

**Results**  
Assignment tab where students see runs, status, and released feedback or grades.

**Rubric**  
Scoring grid with criteria. Faculty edit; students usually read only.

**Speed grading**  
Faculty queue to move through many submissions for one assignment.

**Submission**  
A student’s saved work for an assignment at a point in time.

**Test run**  
Automated execution of the assignment’s test suite against code or files.

**University admin**  
Role that configures institution-wide data such as semesters, courses, and users.
