# Faculty

You use the **Teaching** sidebar: **Dashboard**, **My classes**, **Rubrics**, **Grading assistants**, **Students**, **Schedule**, plus **Materials** and **Discussions** under **Resources**.

Grading is always tied to a **class** and an **assignment**, not a separate global grading home.

## Start here

1. [All faculty actions](../actions/#faculty) lists every route and task.
2. [Courses and classes](../features/courses-and-classes) for class creation and navigation.
3. [Assignments and editor](../features/assignments-and-editor) for create and edit flows.
4. [Grading and feedback](../features/grading-and-feedback) for submission grading and speed grading.
5. [Plagiarism and AI reports](../features/plagiarism-and-ai-reports) for running class-wide style reports.

## Typical setup for a new assignment

1. Open **My classes**, pick the class, go to **Assignments**.
2. **Create assignment**, set language, rubric, tests, groups as needed.
3. Publish or save per your workflow.
4. Grade from the assignment or **Speed grading** when submissions arrive.

**Path (create assignment):** `/faculty/class/{classId}/assignments/create`  
**Example URL:** [https://ulm.gradeforge.tech/faculty/class/4/assignments/create](https://ulm.gradeforge.tech/faculty/class/4/assignments/create)
