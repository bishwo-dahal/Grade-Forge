# Student

You use the **Learning** sidebar: **Dashboard**, **My courses**, **Assignments**, **Calendar**, and **Resources** (**Materials**, **Discussions**).

## Start here

1. [Sign in and account](../features/sign-in-and-account) if you are new.
2. [All student actions](../actions/#student) lists every step with paths and example URLs.
3. [Assignments and editor](../features/assignments-and-editor) explains the workspace tabs.
4. [Tests and submissions](../features/tests-and-submissions) covers **Run tests** and **Submit**.
5. [Grading and feedback](../features/grading-and-feedback) explains where **Results** and grades appear.

## Typical week

1. Check **Assignments** for due work.
2. Open each **assignment**, use **Description**, then **Tests** until you pass checks you care about.
3. **Submit** before the deadline.
4. Return later to **Results** for feedback.

**Path (assignments list):** `/student/assignments`  
**Example URL:** [https://ulm.gradeforge.tech/student/assignments](https://ulm.gradeforge.tech/student/assignments)
