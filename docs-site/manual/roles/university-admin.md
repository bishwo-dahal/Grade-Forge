# University administrator

You work in the **University admin** shell: **Faculty**, **Semesters**, **Courses**, **Languages**, **Manage users**, **Monitor**, and **Settings** (under `/university-admin/settings`, not the student or faculty `/settings` route).

## Start here

1. [All university admin actions](../actions/#university-administrator) lists each screen.
2. [University administration](../features/university-administration) summarizes each area.
3. [Lifecycle](../lifecycle) shows how your setup connects to faculty and student work.

**Path (default landing):** `/university-admin/faculty`  
**Example URL:** `https://gradeforge.tech/university-admin/faculty`
