# Files and downloads

Assignments and submissions use **file upload** and **download** links. Your browser may save files to your **Downloads** folder.

## Student upload

Use the assignment workspace upload control when it appears. Allowed extensions depend on the assignment **language** (for example Python or Java).

**Path:** `/assignment/{assignmentId}`  
**Example URL:** [https://ulm.gradeforge.tech/assignment/12](https://ulm.gradeforge.tech/assignment/12)

## Downloading instructor or submission files

When you see **Download** on a presigned link, use it promptly. Links can **expire** after a short time for security.

## If download fails

- Try again after signing in again.
- Check that your school configured **cloud storage** for the deployment. Local developer setups without storage keys may not download real files. Technical staff should read **[SETUP.md](https://github.com/bishwo-dahal/Grade-Forge/blob/main/SETUP.md)** in the repository.
