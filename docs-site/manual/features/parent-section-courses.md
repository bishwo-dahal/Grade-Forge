# Main course and linked sections

Faculty can designate one **main course** and attach **linked section courses** (separate course rows, usually different section labels). Create and edit assignments and tests on the **main** course, and Grade Forge keeps section copies in sync.

## What to do in the UI

- **Author on the main course:** Open the main course from **My classes**. Use **Assignments** to create or edit work; updates propagate to linked sections after you save.
- **Open a linked section:** In a section course, the header shows **Linked section of …** and an **Open main course** button.
- **Edit inside a linked section:** When an assignment is synced from the main course, the section copy is **schedule-only**:
  - You can change **open / due / late** dates.
  - If it’s a **group** assignment, you can choose the **main group** for this section (your rosters differ).
  - Title, description, language, rubric, points, starter files, and tests stay controlled by the main course.
- **Detach one assignment (optional):** In the section course **Assignments** list, use **Detach from main** if one section needs a one-off variant. After detaching, updates on the main course no longer change that copy.

## What syncs vs. what stays per section

- **Synced from the main course**
  - Assignment content (title, description, language, rubric/points, starter files, tests)
  - New assignments created on the main course
- **Per section**
  - **Schedule**: open / due / late dates (copied when the section assignment is first created, then owned by the section)
  - **Groups**: if the assignment is a group assignment, each section can select its own **main group**
