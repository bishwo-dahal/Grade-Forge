# FAQ

![FAQ page in the documentation site](/manual/images/manual-faq.png)

## How do I run tests before I submit?

1. Open the assignment **Tests** tab.
2. Add code or files, then run tests.

**Path:** `/assignment/{assignmentId}` (Tests tab)  
**Example URL:** [https://ulm.gradeforge.tech/assignment/12](https://ulm.gradeforge.tech/assignment/12)  
**More:** [Tests and submissions](./features/tests-and-submissions)

## How do I use custom stdin with tests?

1. Open **Tests**.
2. Fill the **custom stdin** field when it appears, then run.

**Path:** `/assignment/{assignmentId}` (Tests tab)  
**Example URL:** [https://ulm.gradeforge.tech/assignment/12](https://ulm.gradeforge.tech/assignment/12)

## Where are my grades?

1. Open the **assignment**.
2. Use the **Results** tab for feedback and scores your instructor released.

**Path:** `/assignment/{assignmentId}` (Results tab)  
**Example URL:** [https://ulm.gradeforge.tech/assignment/12](https://ulm.gradeforge.tech/assignment/12)  
**More:** [Grading and feedback](./features/grading-and-feedback)

## Why can I not submit?

The page requires an allowed **upload** or **non-empty editor** content. Read the red or inline message; it states what is missing.

**Path:** `/assignment/{assignmentId}`  
**Example URL:** [https://ulm.gradeforge.tech/assignment/12](https://ulm.gradeforge.tech/assignment/12)

## Where is university admin settings?

Admins use `/university-admin/settings`, not `/settings`.

**Path:** `/university-admin/settings`  
**Example URL:** [https://ulm.gradeforge.tech/university-admin/settings](https://ulm.gradeforge.tech/university-admin/settings)
