# Grade-Forge user manual

Grade-Forge is a web app for university coding courses: classes, assignments, submissions, automated tests, grading, rubrics, and optional similarity and AI-related reports for instructors.

## Who this manual is for

- **Students:** enroll, submit work, run tests, see feedback.
- **Faculty:** run classes, create assignments, grade, manage rubrics and grading assistants.
- **Grading assistants:** help grade inside assigned courses.
- **University administrators:** configure faculty, semesters, courses, languages, users, and monitoring for the institution.

## How to use this site

1. Read [URLs in this manual](./conventions) so paths and example links make sense.
2. Open [All actions by role](./actions/) for a full task list with steps and paths.
3. Use [Roles](./roles/student) for a short tour per role, or [Features](./features/sign-in-and-account) for topic-based help.
